# INST156 Final Project
Steven Su and Jaden Lin

This codebase attempts to replicate and extend some of the findings of the paper "Spatial and temporal variations of
satellite-based aerosol optical depth over Iran in Southwest Asia" as part of the Spring 2025 INST156 course at the
University of Maryland, College Park.

Data was primarily obtained from NASA's Giovanni platform and the downloaded files in the `data/` directory are licensed
under the Giovanni system's policies, except for `Locations.csv`, which was generated by us based on content from the
paper and is licensed with the code under AGPL 3.0.

The `plots/` directory contains the last generated outputs using the code and replicate the figures from the original
paper.

This codebase is written in Python 3 and uses `uv` as the package manager. To run the code, install the dependencies and
run the `main.py` file.
